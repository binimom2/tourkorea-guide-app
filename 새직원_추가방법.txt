  새 직원 / 가이드 추가하는 방법
════════════════════════════════════════════════════

앱에서 "계정 추가"만 하면 명단엔 올라가지만 로그인은 안 됩니다.
아래 순서대로 해야 그 사람이 로그인할 수 있어요.

──────────────────────────────────────────
[1] 앱에서 계정 추가
    - 관리자(admin)로 로그인 → 계정관리 → 새 계정 추가
      (아이디/비밀번호/이름/역할 입력)

[2] 비밀키(secret key) 새로 발급
    - Supabase 대시보드 → tourkorea-guide-app
      → Project Settings → API Keys
    - "Secret keys" 옆 [+ New secret key] 클릭 → 생성된 키 복사

[3] secret.txt 에 키 붙여넣기
    - 이 폴더의 secret.txt 파일 열기 (없으면 새로 만들기)
    - 복사한 키 붙여넣고 저장

[4] 계정생성_실행.bat 더블클릭
    - 새 계정만 [생성], 기존은 [이미있음] 으로 표시
    - "이름표 갱신 완료" 가 나오면 가이드 이름 로그인까지 준비됨

[5] 뒷정리 (중요)
    - secret.txt 내용 지우고 저장 (또는 파일 삭제)
    - Supabase 대시보드에서 방금 만든 secret key 삭제
      (강력한 키라 남겨두지 않는 게 안전)

[6] 끝! 그 사람은 이제 앱에서 로그인 가능
    - 가이드: 이름으로 로그인 / 그 외: 아이디로 로그인
    - 비밀번호는 [1]에서 정한 것

──────────────────────────────────────────

   못 바꿉니다. 비번 변경이 필요하면 클로드에게 요청하세요.
