손님 사이트 「실시간 견적」을 로그인 없이 열기 (테스트 기간용 — 끝나면 다시 잠그기)
=====================================================================
사장님 지시 2026-09-17: 몇 곳에 던져 보는 테스트 동안만 로그인 없이 열고, 이후 다시 잠근다.

■ 어떻게 동작하나
   「실시간 견적」 팝업은 직원용 계산기(/golf/?embed=site)를 그대로 띄운다.
   계산기는 요금표(golf_pricing)와 코드표(golf_codes)를 Supabase에서 직접 읽는데,
   평소에는 로그인한 직원만 읽을 수 있게 잠겨 있어(RLS) 손님에게는 로그인 화면이 뜬다.
   아래 정책을 켜면 로그인 없이도 두 표가 읽히고, 계산기가 「손님 모드」로 열린다.
     · 손님 모드: 견적 이력에 저장 안 됨 · 견적번호는 S번호(직원 G번호와 구분) · 관리 링크 없음
     · 화면에는 지금처럼 1인 요금·총액(마진 포함 손님가)만 보인다.

■ 열기 — Supabase 대시보드 → SQL Editor 에 붙여넣고 실행
   ---------------------------------------------------------------
   create policy "golf 요금표 공개 읽기(테스트)"
     on public.guide_data
     for select
     to anon
     using (data_key in ('golf_pricing', 'golf_codes'));
   ---------------------------------------------------------------
   실행 뒤 로그아웃 상태로 /golf/site/ 에서 「실시간 견적」을 눌러 계산기가 뜨면 된 것.
   (안 뜨면 새로고침 Ctrl+Shift+R 한 번.)

■ 잠그기 — 테스트가 끝나면 이것만 실행 (배포·코드 수정 필요 없음)
   ---------------------------------------------------------------
   drop policy "golf 요금표 공개 읽기(테스트)" on public.guide_data;
   ---------------------------------------------------------------
   실행 뒤에는 예전처럼 로그인 화면이 뜬다.

■ ⚠ 열려 있는 동안 알아 둘 것
   화면에는 손님가만 찍히지만, 요금표 자체(그린피·캐디·카트 원가, 마진, 핸들링·가이드·차량 요금)가
   브라우저로 내려간다. 개발자 도구를 열 줄 아는 사람은 이 자료를 볼 수 있다.
   그래서 테스트가 끝나면 반드시 잠글 것. 원가를 감춘 채 열려면 계산을 서버로 옮기는 별도 작업이 필요하다.
