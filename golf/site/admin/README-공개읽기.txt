관리 화면에서 저장한 내용이 손님에게 보이게 하려면 (한 번만 하면 됩니다)
=====================================================================

■ 지금 상태
   관리 화면에서 「저장」을 누르면 내용은 Supabase(guide_data / golf_site)에 잘 들어갑니다.
   그런데 손님은 로그인이 없어서 그 값을 읽지 못합니다(테이블이 RLS로 잠겨 있음).
   그래서 손님 화면은 data.js에 있는 기본값으로 계속 보입니다.
   → 화면이 비거나 깨지지는 않습니다. 다만 바꾼 내용이 손님에게 안 보일 뿐입니다.

■ 해결 — golf_site 한 줄만 누구나 읽을 수 있게 허용
   Supabase 대시보드 → SQL Editor 에 아래를 붙여넣고 실행하세요.
   (guide_data의 다른 자료는 그대로 잠겨 있습니다. 사이트에 공개할 내용 한 줄만 열립니다.)

   ---------------------------------------------------------------
   create policy "golf_site 공개 읽기"
     on public.guide_data
     for select
     to anon
     using (data_key = 'golf_site');
   ---------------------------------------------------------------

■ 확인 방법
   실행한 뒤 손님 페이지(/golf/site/)를 새로고침하고, 관리 화면에서 바꾼 문구가
   그대로 보이면 된 것입니다.

■ 주의
   이 정책을 켜면 golf_site에 넣은 내용은 인터넷 누구나 볼 수 있습니다.
   그러니 관리 화면에는 원가(그린피·캐디피·써차지)나 담당자 이름을 적지 마세요.
   요금표(golf_pricing)는 이 정책과 무관하게 계속 잠겨 있습니다.
