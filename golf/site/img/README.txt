골프장 · 호텔 사진 넣는 곳
=========================

이 폴더에 사진을 넣고, index.html 의 SITE.photos 에 한 줄 적으면 카드에 붙습니다.
(파일만 보내주시면 제가 넣어드립니다.)

  람차방.jpg
  시암올드.jpg
  블랙마운틴.jpg
  칸타리호텔.jpg

■ 이름은 사이트에 표시되는 이름과 정확히 같아야 합니다
   (index.html 안 SITE.courses / SITE.hotels 의 n 값).
   괄호까지 그대로 씁니다 →  파인애플밸리(구,반얀).jpg

■ 확장자는 jpg / webp / png 셋 다 됩니다. jpg를 먼저 찾습니다.

■ 사진이 없는 곳은 지금처럼 이름이 적힌 초록 칸이 그대로 남습니다.
   62곳을 한 번에 채우지 않아도 됩니다. 있는 것부터 넣으시면 됩니다.

■ 권장 크기
   가로 1200px 안팎, 가로:세로 = 16:10, 한 장 300KB 이하.
   카드가 16:10으로 잘라 보여주므로 가운데에 코스가 오게 찍힌 사진이 좋습니다.

■ 파일명을 다르게 쓰고 싶으면 index.html 데이터에 직접 적어도 됩니다.
   { r:"파타야", n:"람차방", h:"27홀", d:"...", img:"img/laemchabang-1.jpg" }

■ 저작권
   직접 찍으신 사진, 또는 골프장·호텔에서 사용 허락을 받은 사진만 넣어 주세요.
   골프장 홈페이지의 사진을 그대로 가져다 쓰면 문제가 될 수 있습니다.
